# Site improvements — Nov 4, 2026

## Thumbnail overlap — fixed
- The gallery used a JavaScript masonry trick that measured each image and assigned it a grid size. Images that loaded from cache were never measured, so they collapsed to a single 8px row and overlapped the works below. Replaced with pure CSS columns: items flow naturally, keep their real proportions, and cannot overlap. 3 columns on desktop, 2 on tablet, 1 on phone.

## Look — closer to jamesjean.com
- Bigger cells, wider gaps (28px), quieter shadows, softer corners. Captions are small and plain: title, medium, size.

## More info per work — closer to benjamin.klemencic.net
- Every canvas work now shows: title, "Oil on canvas", and an "Inquire about this work" link that emails Greg with the work's title in the subject.
- Every sandpaper work shows: title, "Oil on sandpaper" + dimensions (where the page already listed them), and the same inquire link.
- Clicking a work still expands it full-screen; the expanded view now sits above the header and shows the title/info in readable light text.
- Homepage now has a short artist statement (draft — edit freely).
